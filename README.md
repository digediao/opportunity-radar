# 开源商业机会雷达

一个无人值守的数据网站：每天从 GitHub 的公开仓库数据中筛选近期活跃、许可清晰、具备商业使用价值的工具，自动生成中文网页、RSS 和数据文件。

## 收入逻辑

```text
GitHub 公开数据 → 每日自动筛选/评分/中文摘要 → 静态网站与 RSS
→ 搜索流量、订阅流量和数据使用者 → 广告/联盟链接/付费完整版 CSV/API
```

系统没有人工逐单制作或交付；它按计划运行并重建站点。**变现需要一次性配置自己的收款或广告/联盟账户，且无法保证流量和收入。**

## 零成本运行

要求：Node.js 18+。

```powershell
cd 'D:\低格调\money\机会雷达'
node scripts\run.mjs
```

成功后在 `site\` 下生成：

- `index.html`：可发布的日报页面；
- `data\latest.json`：完整结构化数据；
- `feed.xml`：RSS；
- `data\latest.csv`：可用于后续付费下载的 CSV。

本地预览可直接双击 `site\index.html`。

## 自动运行

`run-daily.cmd` 是每日执行入口。将它在 Windows 任务计划程序中设为每日运行一次即可；默认不会创建任何系统级计划任务，避免在未获确认时修改电脑设置。

## 上线与变现（后续一次性配置）

1. 把 `site/` 发布到静态托管（例如 GitHub Pages 或 Cloudflare Pages 的免费层）。
2. 配置定时任务，让构建结果自动部署。
3. 选择一种合规变现方式：
   - 广告：有稳定自然流量后申请；
   - 联盟：只在真实相关的工具推荐旁放经批准的联盟链接；
   - 付费数据：免费保留前 10 条，完整 CSV/API 使用合法支付平台交付。

不要购买机器人流量、自动点击广告或用该站制造虚假互动。
